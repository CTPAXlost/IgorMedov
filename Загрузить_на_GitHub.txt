ИСПРАВЛЕННАЯ СБОРКА

1. Загрузите всё содержимое папки проекта в корень репозитория.
2. Убедитесь, что файл .github/workflows/build-apk.yml обновился.
3. Откройте Actions -> Сборка APK -> Run workflow.
4. После успешной сборки скачайте Artifact «Ремонтник-Старый-дом-APK».

Старый gradle-wrapper.jar можно удалить из репозитория. Даже если он останется, новый workflow удалит его на runner-е до проверки и не будет его запускать.
