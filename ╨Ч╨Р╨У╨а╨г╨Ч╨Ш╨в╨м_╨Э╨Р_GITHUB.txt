РЕМОНТНИК: СТАРЫЙ ДОМ — V1.1.0

1. Создай новый пустой репозиторий GitHub.
2. Загрузи всё содержимое этой папки, включая скрытую папку .github.
3. Открой Actions → Сборка APK.
4. Нажми Run workflow.
5. После зелёной галочки скачай Artifact «Ремонтник-Старый-дом-APK».
6. Внутри будет готовый файл «Ремонтник-Старый-дом.apk».

В этой версии:
- герой Игорь Мёдов;
- новое качественное cartoon-лицо;
- точная надпись Karma на футболке;
- 5 уровней;
- уровни 4 и 5 повышенной сложности;
- сохранения, настройки, пауза и выход;
- 5 этапов ремонта дома.
