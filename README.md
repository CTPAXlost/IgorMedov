# Ремонтник: Старый дом

Готовая Android-игра-платформер с тремя полноценными уровнями. Проект рассчитан на сборку APK через GitHub Actions или Android Studio.

## Что уже реализовано

- 3 разных уровня: двор, стройка и заброшенный квартал;
- монеты, здоровье, контрольные точки и сохранение прогресса;
- противники, шипы, пропасти, пилы, падающие кирпичи и движущиеся платформы;
- разрушаемые ящики и удар молотком;
- отдельное управление для сенсорного экрана и клавиатуры;
- после каждого уровня герой молотком ремонтирует старый дом;
- после третьего уровня дом полностью восстановлен;
- новый рисованный герой по фотографии-референсу — фотография в игре не используется и не накладывается на тело;
- полноэкранный Android WebView без подключения к интернету.

## Как получить APK на GitHub

1. Создайте пустой репозиторий на GitHub.
2. Загрузите в него **всё содержимое этой папки**, включая скрытую папку `.github`.
3. Откройте вкладку **Actions**.
4. Выберите workflow **«Сборка APK»**.
5. Нажмите **Run workflow**.
6. После завершения откройте запуск и скачайте Artifact **«Ремонтник-Старый-дом-APK»**.

Workflow также автоматически запускается после каждого push в ветку `main` или `master`.

## Сборка на ПК

Требуется Android Studio с Android SDK 35 и Java 17.

### Windows

```bat
gradlew.bat assembleDebug
```

### Linux / macOS

```bash
chmod +x gradlew
./gradlew assembleDebug
```

APK появится здесь:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## Проверка версии в браузере

Откройте `web/index.html` в браузере. Управление на ПК:

- `A/D` или стрелки — движение;
- `Пробел` — прыжок;
- `X`, `E` или левый `Ctrl` — молоток;
- `Esc` — пауза.

На Android отображаются сенсорные кнопки.
