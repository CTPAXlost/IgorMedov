# Ремонтник: Старый дом

Полноценная Android-игра-платформер в духе классических игр типа Mario. Проект написан нативно на Java и не использует WebView, поэтому игра запускается как обычное Android-приложение.

## Что уже реализовано

- главное меню: новая игра, продолжение, выбор уровня, настройки и выход;
- сохранение текущего уровня, контрольной точки, монет и открытых уровней;
- три полноценных уровня с боковой прокруткой;
- монеты, ящики, враги, шипы, пропасти и контрольные точки;
- управление с экрана Android и с клавиатуры на эмуляторе;
- удар молотком и разрушение ящиков;
- пауза, сохранение и выход в меню;
- отдельная анимационная сцена ремонта старого дома после каждого уровня;
- финальная сцена полностью восстановленного дома;
- качественно нарисованный программно персонаж: короткие тёмные волосы, узнаваемые черты лица, чёрная футболка KARMA, рабочие брюки, кроссовки и молоток;
- музыка, звуки, вибрация и изменение размера экранных кнопок;
- автоматическая сборка APK через GitHub Actions.

## Управление

### Android

- слева: движение;
- стрелка вверх: прыжок;
- молоток: удар;
- кнопка `Ⅱ` вверху: пауза.

### ПК / Android-эмулятор

- `A` / `D` или стрелки — движение;
- `Пробел`, `W` или стрелка вверх — прыжок;
- `E` или левый Ctrl — молоток;
- `Esc` или `P` — пауза.

## Сборка APK на GitHub

1. Создайте пустой репозиторий GitHub.
2. Загрузите в него **всё содержимое этой папки**, включая скрытую папку `.github`.
3. Откройте вкладку **Actions**.
4. Выберите workflow **Сборка APK**.
5. Нажмите **Run workflow**.
6. После завершения скачайте Artifact **Ремонтник-Старый-дом-APK**.
7. Внутри будет файл `Ремонтник-Старый-дом.apk`.

Workflow сам устанавливает Java 17, Android SDK 35, Build Tools 35.0.0 и Gradle 8.9.

## Открытие в Android Studio

Откройте корневую папку проекта. Android Studio предложит синхронизировать Gradle. Для запуска выберите устройство Android и нажмите Run.

## Технические параметры

- package: `ru.karma.remontnik`;
- minSdk: 24;
- targetSdk / compileSdk: 35;
- ориентация: альбомная;
- движок игры: собственный игровой цикл на `SurfaceView` и `Canvas`;
- внешние библиотеки отсутствуют.
