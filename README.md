# Ремонтник: Старый дом

Android-игра-платформер с тремя уровнями. Герой собирает монеты, преодолевает препятствия, использует молоток, а после каждого пройденного уровня ремонтирует очередную часть старого дома.

## Реализовано

- три уровня: двор, стройка и заброшенный квартал;
- монеты, здоровье, противники, шипы, пропасти, пилы и падающие кирпичи;
- движущиеся платформы, контрольные точки и сохранение прогресса;
- прыжок, бег и удар молотком;
- сенсорное управление на Android и клавиатура на ПК;
- отдельная сцена ремонта дома после каждого уровня;
- рисованный игровой герой вместо криво вырезанной фотографии;
- автономная работа без подключения к интернету.

## Сборка APK через GitHub

1. Загрузите всё содержимое проекта в корень репозитория, включая папку `.github`.
2. Откройте вкладку **Actions**.
3. Выберите **Сборка APK**.
4. Нажмите **Run workflow**.
5. После зелёной сборки откройте запуск и скачайте Artifact **Ремонтник-Старый-дом-APK**.

APK внутри Artifact называется `Ремонтник-Старый-дом.apk`.

## Исправленная ошибка Gradle Wrapper

Предыдущая сборка останавливалась на этапе **Подготовить Gradle** с сообщением `At least one Gradle Wrapper Jar failed validation`. Причиной был нестандартный `gradle-wrapper.jar`.

Исправленный workflow удаляет старый Wrapper на runner-е и устанавливает официальный Gradle 8.9 через `gradle/actions/setup-gradle`, после чего выполняет сборку командой `gradle assembleDebug`.

## Локальная сборка

Основной способ — GitHub Actions. Также проект можно открыть в Android Studio с Java 17 и Android SDK 35 и выбрать **Build → Build APK**.

Для браузерной проверки откройте `web/index.html`.

Управление на ПК:

- `A/D` или стрелки — движение;
- `Пробел` — прыжок;
- `X`, `E` или левый `Ctrl` — молоток;
- `Esc` — пауза.
