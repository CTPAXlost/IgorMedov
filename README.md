# Ремонтник: Старый дом — версия 1.1.0

Нативная Android-игра-платформер с боковой прокруткой. Главный герой — **Игорь Мёдов**. Проект написан на Java, использует `SurfaceView`/`Canvas` и не содержит WebView.

## Изменения версии 1.1.0

- главный герой полностью перерисован внутри игры;
- новое узнаваемое cartoon-лицо с более подробной формой головы, скулами, челюстью, носом, глазами, губами, короткой стрижкой и светотенью;
- на футболке точная надпись **Karma**;
- имя **Игорь Мёдов** добавлено в игру и финальную сцену;
- количество уровней увеличено с трёх до **пяти**;
- уровни 4 и 5 заметно сложнее: более длинные маршруты, короткие платформы, увеличенные пропасти, быстрые враги, огонь и вращающиеся пилы;
- меню выбора уровня переработано под пять карточек;
- сохранение и открытие уровней расширено до пятого уровня;
- ремонт дома теперь состоит из пяти последовательных этапов;
- обновлена финальная сцена полностью восстановленного дома.

## Что реализовано

- главное меню: новая игра, продолжение, выбор уровня, настройки и выход;
- сохранение уровня, контрольной точки, монет и открытого прогресса;
- пять полноценных уровней с постепенным ростом сложности;
- монеты, ящики, четыре типа врагов, шипы, раскалённые ловушки, огонь, пилы и пропасти;
- управление с экрана Android и с клавиатуры на эмуляторе;
- прыжок, удар молотком, уничтожение врагов и разрушение ящиков;
- пауза, сохранение и выход в меню;
- анимация ремонта старого дома после каждого уровня;
- музыка, звуки, вибрация и три размера экранных кнопок;
- автоматическая сборка APK через GitHub Actions.

## Управление

### Android

- слева: движение;
- стрелка вверх: прыжок;
- кнопка с молотком: удар;
- кнопка `Ⅱ`: пауза.

### ПК / Android-эмулятор

- `A` / `D` или стрелки — движение;
- `Пробел`, `W` или стрелка вверх — прыжок;
- `E` или левый Ctrl — удар молотком;
- `Esc` или `P` — пауза.

## Сборка APK на GitHub

1. Создайте пустой репозиторий GitHub.
2. Загрузите в него **всё содержимое этой папки**, включая скрытую папку `.github`.
3. Откройте вкладку **Actions**.
4. Выберите workflow **Сборка APK**.
5. Нажмите **Run workflow**.
6. После завершения скачайте Artifact **Ремонтник-Старый-дом-APK**.
7. Внутри будет файл `Ремонтник-Старый-дом.apk` и его SHA-256.

Workflow устанавливает Java 17, Android SDK 35, Build Tools 35.0.0 и Gradle 8.9, выполняет `lintDebug`, затем собирает debug APK.

## Открытие в Android Studio

Откройте корневую папку проекта, дождитесь синхронизации Gradle, выберите Android-устройство и нажмите **Run**.

## Технические параметры

- package: `ru.karma.remontnik`;
- version: `1.1.0` (`versionCode 5`);
- minSdk: 24;
- targetSdk / compileSdk: 35;
- ориентация: альбомная;
- внешние библиотеки отсутствуют.
