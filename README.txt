РЕМОНТНИК: СТАРЫЙ ДОМ — ПЕРВАЯ ИГРОВАЯ ВЕРСИЯ

Что уже сделано
----------------
• Полноценная 2D-игра-платформер в духе классических игр про прыжки и монеты.
• Главный герой использует лицо с предоставленной фотографии.
• Три завершённых уровня с разной графикой и сложностью:
  1. «Старый двор» — обучение, ямы, шипы, ящики, враги и движущиеся платформы.
  2. «Большая стройка» — пилы, падающие кирпичи и сложные платформы.
  3. «Заброшенный квартал» — ночной финальный уровень с усиленными препятствиями.
• Монеты, три сердца здоровья, контрольные точки, молоток и разрушаемые ящики.
• После каждого уровня герой достаёт молоток и ремонтирует следующую часть старого дома.
• После третьего уровня дом становится полностью восстановленным.
• Выбор уровней, сохранение прогресса и лучших результатов по монетам.
• Сенсорные кнопки для Android и клавиатурное управление на ПК.

Управление на ПК
----------------
A / D или стрелки — движение
Пробел / W / стрелка вверх — прыжок
X / E / левый Ctrl — удар молотком
Esc — пауза / назад

Быстрый запуск на ПК
--------------------
Запустите файл «Запустить_на_ПК.bat».
Также можно открыть web\index.html вручную в Chrome или Edge.

Сборка APK на Windows
---------------------
Вариант 1 — самый простой:
1. Установите Android Studio и Android SDK 35.
2. Откройте папку android как проект.
3. Дождитесь синхронизации Gradle.
4. Выберите Build → Build APK(s).

Вариант 2:
1. Установите Android Studio или JDK 17 и Android SDK.
2. Запустите «Собрать_APK.bat».
3. После успешной сборки рядом появится файл «Ремонтник_3_уровня.apk».

Где находится APK после обычной сборки
--------------------------------------
android\app\build\outputs\apk\debug\app-debug.apk

Структура проекта
-----------------
web      — версия для запуска и проверки на ПК
android  — полноценный Android Studio проект
скриншоты — изображения текущей версии
